# Training data separation and recovery regressions

## Position-disjoint validation

`neural/data_split.py` defines `position-blake2b-v1`. It reserves one tenth
of position groups using a fixed BLAKE2b hash, not sampling seeds or filenames.
The identity includes board dimensions, connect length, Classic/Chaos rules,
and both mover-relative piece masks. Horizontal reflections are canonicalised
because training uses reflection augmentation. Repetition-feature variants stay
in the same group. Gravity-changing flips and rotations are moves, not reflection
augmentation symmetries.

The builder samples shard `0000` only from reserved groups and later shards only
from training groups. Appending with a different seed cannot change membership.
The loader also filters legacy exact files and all self-play replay, so old
files do not need to be regenerated merely to enforce the new split. Directory
search-quality sweeps apply the same filter before reporting held-out results.
Single-file search-quality runs remain generic diagnostics, not a guarantee
that the supplied file is a holdout.

`DISTILL_HOLDOUT_CONFIGS` still excludes entire configurations from training,
including transposed Chaos orientations. That stronger exclusion takes priority
over the default position split. A first shard from such a configuration can
be evaluated in full. Empty training splits fail instead of consuming validation.

Checkpoints written by distillation now record the split version and explicit
holdout configuration. These code changes do not erase leakage from previously
trained weights or retroactively validate historical metrics. For a clean
unseen-position measurement, train from scratch using the new split, or use a
checkpoint known to have used it. No cloud jobs, model files or policy tables
are redeployed or regenerated by this patch.

## Strict replay budget

`DISTILL_REPLAY_WINDOW` is an exact upper bound on eligible replay positions,
not a whole-file target. The loader scans newest files and rows first, excludes
validation/held-out configurations, and slices the last chunk to the remaining
allowance. Every training tensor is sliced together. Filtering uses bounded
chunks rather than copying complete replay files. A zero window disables replay;
a negative window is rejected. Exact training positions are outside this replay
budget.

## Regression commands

```sh
node --test tests/undo-transaction.test.js
python -m neural.test_review
python -m neural.test_rereview
python scripts/rereview-browser-regressions.py --browser chromium
python scripts/rereview-browser-regressions.py --browser webkit
```

The browser test aborts a real IndexedDB write after request success but before
transaction commit. Undo must retain its board and receipt, including through
reload, and a successful retry reverses exactly one result. Normally a completed
round is not restored; only a round with a pending score reversal is retained.
The CPU tests reach the production MCTS depth guard and verify the cached leaf
value is backed up with the correct sign rather than substituted with zero.
